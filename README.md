# 🚀 Leapsome Prompt Pilot

> **Let your browser agent navigate the training. You keep the knowledge.**  
> **Deixe seu agente navegar pelo treinamento. Você fica com o conhecimento.**

A community-maintained collection of **copy-and-paste prompts** designed for browser-capable AI assistants to help users navigate, understand, test, and review corporate training paths in Leapsome.

Uma coleção colaborativa de **prompts para copiar e colar**, criada para assistentes de IA com acesso ao navegador ajudarem usuários a navegar, compreender, testar e revisar treinamentos corporativos no Leapsome.

---

## 🇺🇸 English

### What is this?

Leapsome Prompt Pilot is intentionally simple: **there is no application to install and no code to run**.

1. Open the Leapsome training you are authorized to take or test.
2. Open a browser-capable AI assistant or browser extension.
3. Copy the English prompt from:
   - [Universal Training Agent — English](prompts/universal-training-agent.en.md)
4. Paste it into the assistant.
5. Keep the training tab open and supervise the run.
6. Take over whenever the training requires a personal declaration, attestation, policy acceptance, certification, identity verification, or another action that must genuinely come from you.

The prompt is written to help an agent inspect page content, follow modules, expand hidden sections, use transcripts when available, answer ordinary knowledge checks from the training material, record problems, and produce a final structured review.

### Designed for

The prompt can be adapted to browser agents such as:

- ChatGPT / Codex browser workflows
- Claude browser extensions or browser agents
- other assistants that can inspect and interact with the current browser tab

This repository is **not affiliated with, endorsed by, or maintained by Leapsome, OpenAI, Anthropic, or any employer**.

### What the agent should do

The universal prompt asks the agent to:

- navigate the complete training path;
- read relevant text and interactive content;
- inspect accordions, cards, tabs, PDFs, transcripts, and related material when needed;
- complete ordinary navigation actions;
- reason about quizzes using the training material;
- keep a traceable internal summary of modules, concepts, answers, issues, and pending steps;
- stop when human intervention is required;
- produce a professional final training report.

### Human-only actions

The prompt explicitly instructs the agent **not to impersonate the user**.

A human should personally handle actions such as:

- legal or employment attestations;
- policy acceptance;
- declarations of personal understanding;
- certifications made in the employee's name;
- identity checks;
- signatures;
- acknowledgements whose truth depends on the user's personal state or intent.

Use this project only where automation or AI assistance is permitted by your employer, training provider, and applicable rules.

### Community prompts

Different trainings may benefit from specialized prompts. Community contributions are welcome.

Examples:

- security awareness;
- AML / KYC / compliance;
- onboarding;
- privacy and data protection;
- workplace safety;
- product training;
- customer support;
- engineering or technical training.

See [Community Prompts](prompts/community/README.md).

### Contributing

You can improve the universal prompt, translate it, create a specialized prompt, improve documentation, or report behavior that does not work well.

Read [CONTRIBUTING.md](CONTRIBUTING.md).

## 🇧🇷 Português do Brasil

### O que é este projeto?

O Leapsome Prompt Pilot é propositalmente simples: **não existe aplicativo para instalar e não há código para executar**.

1. Abra o treinamento do Leapsome que você está autorizado a realizar ou testar.
2. Abra um assistente de IA com capacidade de interagir com o navegador.
3. Copie o prompt em português:
   - [Agente Universal de Treinamento — PT-BR](prompts/universal-training-agent.pt-BR.md)
4. Cole o texto no assistente.
5. Mantenha a aba do treinamento aberta e supervisione a execução.
6. Assuma o controle quando o treinamento exigir uma declaração pessoal, aceite de política, certificação, verificação de identidade ou outra ação que precise genuinamente ser realizada por você.

O prompt foi criado para ajudar o agente a inspecionar o conteúdo da página, percorrer módulos, abrir conteúdo oculto, usar transcrições quando disponíveis, responder verificações comuns de conhecimento usando o próprio material do treinamento, registrar problemas e produzir uma análise estruturada ao final.

### Compatibilidade

O prompt pode ser adaptado para agentes de navegador como:

- ChatGPT / Codex com acesso ao navegador;
- extensões ou agentes de navegador do Claude;
- outros assistentes capazes de inspecionar e interagir com a aba atual.

Este repositório **não possui afiliação, endosso ou manutenção oficial da Leapsome, OpenAI, Anthropic ou de qualquer empregador**.

### O que o agente deve fazer

O prompt universal instrui o agente a:

- navegar pelo Path completo;
- ler textos e conteúdos interativos relevantes;
- abrir acordeões, cartões, abas, PDFs, transcrições e materiais relacionados quando necessário;
- realizar ações normais de navegação;
- raciocinar sobre quizzes utilizando o conteúdo do treinamento;
- manter um registro interno rastreável de módulos, conceitos, respostas, problemas e pendências;
- parar quando for necessária intervenção humana;
- gerar um relatório profissional ao final.

### Ações que devem continuar humanas

O prompt instrui explicitamente o agente a **não se passar pelo usuário**.

A pessoa deve realizar pessoalmente ações como:

- atestados legais ou trabalhistas;
- aceite de políticas;
- declarações pessoais de compreensão;
- certificações realizadas em nome do funcionário;
- verificações de identidade;
- assinaturas;
- confirmações cuja veracidade dependa do estado, intenção ou conhecimento pessoal do usuário.

Utilize este projeto somente quando automação ou assistência por IA for permitida pelo seu empregador, pelo provedor do treinamento e pelas regras aplicáveis.
