# Contributing / Como contribuir

Thank you for helping improve Leapsome Prompt Pilot.  
Obrigado por ajudar a melhorar o Leapsome Prompt Pilot.

## 🇺🇸 English

### Good contributions

We welcome:

- improvements to the universal prompt;
- clearer browser-navigation instructions;
- accessibility improvements;
- better completion checks;
- specialized community prompts;
- translations;
- documentation fixes;
- reports of ambiguous or unreliable agent behavior.

### Pull requests

1. Fork the repository.
2. Create a focused branch.
3. Make one clear improvement.
4. Explain what problem the change solves.
5. Mention which browser agent or extension you tested, if applicable.
6. Open a pull request.

For prompt changes, prefer small, reviewable edits over large rewrites unless a rewrite is genuinely necessary.

### Safety and privacy

Do not contribute:

- passwords, tokens, cookies, session IDs, API keys, or credentials;
- private company training content;
- copyrighted material you do not have permission to redistribute;
- personal information;
- prompts intended to falsify attendance, identity, signatures, attestations, or personal acknowledgements;
- instructions to bypass access controls or unrelated security mechanisms.

Prompts may assist with ordinary navigation and knowledge checks, but personal declarations and identity-dependent actions should remain human.

### Specialized prompts

Place community prompts under:

```
prompts/community/
```

Use descriptive filenames and include both language versions when possible.

## 🇧🇷 Português do Brasil

### Boas contribuições

São bem-vindos:

- melhorias no prompt universal;
- instruções mais claras de navegação no navegador;
- melhorias de acessibilidade;
- melhores verificações de conclusão;
- prompts especializados;
- traduções;
- correções de documentação;
- relatos de comportamentos ambíguos ou pouco confiáveis dos agentes.

### Pull requests

1. Faça um fork do repositório.
2. Crie uma branch focada na alteração.
3. Faça uma melhoria clara.
4. Explique qual problema a mudança resolve.
5. Informe qual agente ou extensão de navegador foi testado, quando aplicável.
6. Abra um Pull Request.

Para alterações de prompt, prefira mudanças pequenas e fáceis de revisar em vez de grandes reescritas, exceto quando uma reescrita for realmente necessária.

### Segurança e privacidade

Não envie:

- senhas, tokens, cookies, IDs de sessão, chaves de API ou credenciais;
- conteúdo privado de treinamentos empresariais;
- material protegido por direitos autorais sem permissão de redistribuição;
- informações pessoais;
- prompts destinados a falsificar presença, identidade, assinaturas, atestados ou confirmações pessoais;
- instruções para contornar controles de acesso ou mecanismos de segurança não relacionados.

Os prompts podem auxiliar em navegação normal e verificações comuns de conhecimento, mas declarações pessoais e ações dependentes de identidade devem continuar humanas.

### Prompts especializados

Adicione prompts da comunidade em:

```
prompts/community/
```

Utilize nomes descritivos e, quando possível, inclua versões nos dois idiomas.
