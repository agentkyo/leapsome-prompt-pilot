# Community Prompts / Prompts da Comunidade

## 🇺🇸 English

This folder is for specialized prompts contributed by the community.

A specialized prompt should improve the universal workflow for a particular training domain without pretending to be the learner.

Suggested filename format:

```
topic-name.en.md
topic-name.pt-BR.md
```

Examples:

```
security-awareness.en.md
aml-kyc.pt-BR.md
privacy-training.en.md
```

Please include:

- intended training topic;
- tested browser agent, when relevant;
- what was changed from the universal prompt;
- limitations;
- human-only checkpoints;
- the complete copy-and-paste prompt.

Do not include credentials, private company material, proprietary training answers, personal information, or content you do not have permission to publish.

## 🇧🇷 Português do Brasil

Esta pasta é destinada a prompts especializados enviados pela comunidade.

Um prompt especializado deve melhorar o fluxo universal para um tema específico de treinamento sem se passar pelo aluno.

Formato sugerido para nomes de arquivos:

```
nome-do-tema.en.md
nome-do-tema.pt-BR.md
```

Inclua:

- tema de treinamento pretendido;
- agente de navegador testado, quando relevante;
- alterações realizadas em relação ao prompt universal;
- limitações;
- pontos de intervenção humana;
- prompt completo para copiar e colar.

Não inclua credenciais, materiais privados de empresas, respostas proprietárias de treinamentos, informações pessoais ou conteúdo que você não tenha permissão para publicar.
